# وب‌سایت نازنین غلامی | نمونه صفحه معرفی مشاور

قالب استاتیک فارسی و راست‌چین برای معرفی خدمات روان‌شناسی کودک، بزرگسال و خانواده.

## اجرا
- فایل `index.html` را در مرورگر باز کنید.
- برای توسعه محلی می‌توانید از افزونه Live Server در VS Code استفاده کنید.

## انتشار در GitHub Pages
1. یک Repository جدید در GitHub بسازید.
2. فایل‌های `index.html`، `style.css`، `script.js` و پوشه `assets` را در ریشه مخزن بارگذاری کنید.
3. از مسیر **Settings → Pages**، گزینه **Deploy from a branch** را انتخاب کنید.
4. شاخه `main` و پوشه `/ (root)` را انتخاب و Save کنید.
5. پس از چند دقیقه، آدرس سایت در همان صفحه نمایش داده می‌شود.

## سفارشی‌سازی پیش از انتشار
- شماره تماس و آدرس دقیق را در بخش تماس با ما جایگزین کنید.
- اطلاعات تحصیلی، مجوزها و سوابق حرفه‌ای را فقط پس از تأیید مشاور اضافه کنید.
- فرم رزرو فعلاً نمایشی است و اطلاعات را ذخیره یا ارسال نمی‌کند؛ برای رزرو واقعی باید به بک‌اند، فرم‌ساز یا سرویس پیامکی متصل شود.
- کارت دوره‌ها و مقاله‌ها نمونه هستند و باید به صفحات واقعی متصل شوند.
- تصاویر و فونت از سرویس‌های خارجی بارگذاری می‌شوند و برای استفاده آفلاین باید فایل‌های آن‌ها را به‌صورت محلی اضافه کنید.

## فناوری‌ها
HTML5، CSS3، JavaScript خام، فونت Vazirmatn از Google Fonts.
